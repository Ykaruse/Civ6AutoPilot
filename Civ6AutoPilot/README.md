# 文明6 自动托管（Civ6 Auto Pilot）

一个只改 UI 逻辑、不改数据库的《文明 VI》辅助模组。

## 功能

1. **城市自动生产**
   - 城市生产队列为空时，自动选择下一个生产项目。
   - 使用游戏自带的城市 AI 推荐（`CityAI:GetBuildRecommendations()`），会结合城市人口、区域、建筑、单位需求、当前局势给出推荐，而不是固定建造顺序。
   - 优先修复被掠夺的**区域**和**建筑**。
   - 生产顺序固定为：**区域/建筑 → 奇观 → 单位**。
   - 单位阶段**只生产建造者**；不会生产开拓者、军事单位或其他单位。
   - **社区（Neighborhood）永远不参与任何自动判断**：无论自动选点开关开还是关，都不自动建造、不自动选点、不自动修复，需要你自己建。
   - **城市里已经有建造者时，不会继续造建造者**；轮到建造者兜底时，改跑项目“学院研究补助金”（需要学院）。
   - **自动选点开关（默认关闭）**：
     - 关闭时：优先自动建造市场、银行等不需要选点的建筑；如果没有任何免选点建筑，但存在**有合法放置位置**的新区域/奇观（社区除外），就不自动生产，留给你自己选位置；只有当既没有免选点建筑、也没有任何合法可放置的区域/奇观（社区不算）时，才自动补一个**建造者**兜底。
     - 开启时：电脑全自动，区域/奇观/建筑自动选点，单位阶段只生产建造者。
   - 只在城市空闲时接管；你手动排入的队列不会被覆盖。

2. **未来科技 / 未来市政循环**
   - 当所有非重复科技研究完成后，自动持续选择“未来科技”。
   - 当所有非重复市政完成后，自动持续选择“未来市政”。
   - 科技/市政完成事件触发时也会立即补选，不会停在选择界面。
   - 游戏侧脚本会在完成瞬间重新开始未来循环，避免被“选择科技/市政”挡住。
   - **Future Tech / Future Civic 完成时不再弹出全屏“研究完成”窗口**；普通科技/市政的完成弹窗保持不变。

## 安装

把整个 `Civ6AutoPilot` 文件夹放到：

```
%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Mods\
```

也就是：

```
C:\Users\<你的用户名>\Documents\My Games\Sid Meier's Civilization VI\Mods\Civ6AutoPilot\
```

启动游戏 → **附加内容** → 启用“文明6 自动托管” → 开始/读取游戏。

安装或更新后请**完全退出游戏再重新启动**；只在读档界面加载不会重新解析 `.modinfo`。模组本身不写入游戏数据库，旧存档也可以直接使用。

## 使用

进入游戏后，顶部快捷栏最右侧会出现圆形 **“自动”** 按钮（原“建造者自动改良”齿轮的位置）。点击后可分别开关：

- 自动城市生产（不造开拓者）
- 自动循环未来科技 / 未来市政
- 自动选择区域/奇观位置（默认关闭）

当前默认：**城市自动生产关闭，未来科技/市政循环开启，自动选点关闭**。设置会写入当前玩家配置，下次进入游戏保留。面板上的 **“立即运行”** 可以不等下一回合，立刻执行一次自动托管。

## 兼容性

- 支持原版、迭起兴衰（Expansion1）、风云变幻（Expansion2）。
- 不修改单位、建筑、区域、科技、市政数据，可与绝大多数 UI/数据模组共用。
- 仅对**本地人类玩家**生效；多人模式未做同步处理，不建议在多人游戏中使用。
- 不控制建造者，也不移动任何单位；建造者仍由你自己操作。
- 如果检测到旧“建造者自动改良”模组的顶部齿轮，会直接接管该按钮：点击它打开自动托管面板，旧模组的齿轮设置入口不再打开。这样按钮位置和点击区域都是原生的，不会出现看得见点不到的问题。
- 被掠夺的区域/建筑由城市生产逻辑自动排入修复。

## 排查

如果按钮没有出现或功能没有生效，查看：

```
%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log
```

搜索 `[AutoPilot]`。模组自身只在出错时打印 `[AutoPilot] ERROR: ...`。

## 文件

- `Civ6AutoPilot.modinfo` — 模组注册
- `UI/AutoPilot.xml` / `UI/AutoPilot.lua` — 面板、城市生产、未来循环的 UI 侧逻辑
- `UI/Replacements/TechCivicCompletedPopup_AutoPilot.lua` — 屏蔽 Future Tech/Civic 的完成弹窗
- `Scripts/AutoPilotGameplay.lua` — 未来科技/市政完成后的游戏侧重启，避免停在选择界面
- `Text/AutoPilot_ConfigText.xml` — 模组名称/说明
- `Text/AutoPilot_Text.xml` — 面板文本
